## Featured Project

### OpenID Mini

A learning-focused OAuth 2.0 + OpenID Connect identity provider built from scratch to understand how third-party login systems like "Login with Google" work internally.

Highlights:

- OAuth 2.0 Authorization Code Flow
- OpenID Connect basics
- Client registration and consent flow
- Access token and ID token handling
- `/.well-known/openid-configuration`
- `/.well-known/jwks.json`
- `RS256` signed ID tokens with JWKS verification
- Separate React frontend and Express backend

Repository:

- [OpenID Mini](https://github.com/kunalbhanuse/openID-mini)
